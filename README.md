# kinmove_flutter

Application mobile KinMove V2 — Chauffeurs & Clients

---

## ✨ Fonctionnalités

- Connexion anonyme (UID stable par appareil)
- Finance & Direction (e-mail/mot de passe)
- Système de récompenses (barème Moto 20 / Taxi 30 / Taxibus 20 / Location 100 / Déménagement 100 / Marchandises 50 / Camion 100 CDF)
- Retraits Mobile Money (minimum 5 000 CDF)
- Suivi GPS en temps réel (Leaflet + OpenStreetMap)
- Tableau de bord admin (validation / rejet / paiement)

---
